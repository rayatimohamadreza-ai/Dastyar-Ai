# دستیار اس ممد | SM Mammad AI

اپلیکیشن اندروید فارسی با رابط بومی و چت‌بات هوش مصنوعی آنلاین از مسیر مدل‌های رایگان.

## اتصال هوش مصنوعی
- برنامه از API سازگار با OpenAI در OpenRouter استفاده می‌کند.
- مدل در کد روی `openrouter/free` تنظیم شده تا فقط مدل‌های رایگان قابل مسیریابی انتخاب شوند.
- برای فعال‌سازی، کاربر باید یک حساب رایگان OpenRouter بسازد، کلید API را از `https://openrouter.ai/keys` بگیرد و داخل تنظیمات برنامه وارد کند.
- کلید در خود گوشی با Android Keystore و AES-GCM رمزگذاری و ذخیره می‌شود؛ کلید در مخزن GitHub یا کد برنامه قرار نمی‌گیرد.
- استفاده به اینترنت نیاز دارد. سهمیه و دسترس‌پذیری مدل‌های رایگان تابع محدودیت‌های OpenRouter و ارائه‌دهندگان مدل است؛ رایگان بودن به معنی نامحدود یا تضمین دائمی نیست.
- برنامه برای درخواست‌های چت از `https://openrouter.ai/api/v1/chat/completions` استفاده می‌کند.

## حریم خصوصی و امنیت
- پیام‌های چت برای تولید پاسخ به سرویس OpenRouter و ارائه‌دهنده مدلی که درخواست را پردازش می‌کند ارسال می‌شوند؛ پس این نسخه آفلاین و بدون ارسال داده نیست.
- کلید API در مخزن کد قرار نمی‌گیرد و در حافظه خصوصی برنامه به‌صورت رمزگذاری‌شده نگهداری می‌شود.
- کلید شخصی خود را در پیام‌رسان یا مخزن عمومی منتشر نکنید.

## ساخت APK
GitHub Actions با workflow به نام Android APK فایل debug APK را می‌سازد و به‌صورت artifact منتشر می‌کند.

## توسعه‌های بعدی
- بهبود مدیریت خطا، انتخاب مدل رایگان جایگزین و نمایش وضعیت سهمیه
- ورودی صوتی و تبدیل گفتار به متن
- تحلیل تصویر و تولید تصویر، در صورت وجود سرویس رایگان سازگار
- راهنمای تخصصی تعمیر برد و لوازم خانگی کوچک
