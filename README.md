# دستیار اس ممد | SM Mammad AI

پروژه اندروید فارسی با هدف اجرای مستقل و آفلاین.

## وضعیت فعلی
این مخزن اکنون شامل پوسته بومی اندروید و رابط گفت‌وگوی فارسی است. در این مرحله **مدل زبانی محلی هنوز ادغام نشده**؛ بنابراین برنامه فعلی را نباید هوش مصنوعی مولد کامل یا نسخه نهایی دانست.

## ساخت
GitHub Actions با workflow به نام Android APK فایل debug APK را می‌سازد و به‌صورت artifact منتشر می‌کند.

## هدف معماری
- رابط و داده‌های پایه کاملاً محلی
- عدم ارسال گفتگوها به سرور
- افزودن موتور استنتاج و مدل محلی سازگار با حافظه و پردازنده دستگاه
- عدم نیاز به API key یا اشتراک

## محدودیت سخت‌افزار
مدل‌های زبانی محلی معمولاً چند گیگابایت فضا و حافظه نیاز دارند. مدل مناسب باید جداگانه از نظر مجوز، حجم و عملکرد روی Redmi Note 8 آزمایش شود.
